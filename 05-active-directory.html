2. Add the DC to /etc/hosts

/etc/hosts entry — Kerberos requires FQDN, not IP
required
Why: Kerberos binds tickets to SPNs that include the hostname. Using IP gets KDC_ERR_C_PRINCIPAL_UNKNOWN even with correct creds. Add DC + domain + short alias all in one line.
# One-shot add (uses your $DC_IP, $DC_HOST, $DOMAIN variables):
echo "$DC_IP $DC_HOST $DOMAIN $(echo $DC_HOST | cut -d. -f1)" | sudo tee -a /etc/hosts
# Adds:   10.0.0.10  dc01.corp.local  corp.local  dc01

# Verify both lookups work:
nslookup $DC_HOST
nslookup $DOMAIN
getent hosts $DC_HOST

# Shortcut alias (from install-ad-tools.sh):
dc-host $DC_IP $DC_HOST

# When pivoting — add each new host as you find them:
echo "10.0.0.15 ws01.corp.local ws01" | sudo tee -a /etc/hosts

4. Configure /etc/krb5.conf (only if needed)

Did you leave the krb5-user install prompt blank? That was correct. You're a pentester switching domains every engagement, not a domain user. Configure per-engagement using the template below.
do I need krb5.conf?
Don't need it: impacket-* tools, certipy, kerbrute, evil-winrm, nxc — these accept realm via flags.

Do need it: running kinit directly, PKINIT cert auth flows, some tools that internally call libkrb5.

👥 Anonymous User Enumeration — 5 Methods, Try All
Different protocols leak usernames via different mechanisms. When one method returns 0 valid users, try the others — they have different ACL gates. Real friction from Vulnnet:Roasted — kerbrute returned 0, impacket-lookupsid returned 9 users.
MethodProtocolAnon?Notes
kerbrute userenumKerberos (pre-auth probe)YesDefault expected method. Can be silenced by DC config (returns 0 for everything).
impacket-lookupsidMS-LSAT / LSARPCYes⭐ RID cycles via LSA — works when Kerberos is muted. Often THE winner on labs.
nxc smb --rid-bruteMS-SAMRYesSame as rpcclient via SAMR API — different client/timing.

parallel anonymous user enumeration — try all 5
essential
What this does: Runs all five anonymous enumeration methods and combines results. Different protocols leak users through different LSA/SAMR/Kerberos endpoints — when one is gated, others often aren't.
# 1. Kerbrute (Kerberos pre-auth):

  /usr/share/seclists/Usernames/Names/names.txt \
  -o enum/kerbrute-users.txt 2>/dev/null

# 2. impacket-lookupsid (LSARPC RID cycling) — ⭐ often the winner:
impacket-lookupsid anonymous@$DC_IP 20000 2>/dev/null | \
  grep "SidTypeUser" | awk -F'\' '{print $2}' | awk '{print $1}' \
  > enum/lookupsid-users.txt

# 3. nxc RID brute (via SMB SAMR):
nxc smb $DC_IP -u '' -p '' --rid-brute 10000 2>/dev/null | \
  grep -i "SidTypeUser" | awk '{print $6}' | cut -d'\' -f2 \
  > enum/nxc-rid.txt

# 4. rpcclient enumdomusers (also SAMR but different client):
rpcclient -U "" -N $DC_IP -c "enumdomusers" 2>/dev/null | \
  grep -oP 'user:\[\K[^\]]+' \
  > enum/rpc-users.txt

# 5. enum4linux-ng RID cycling:
enum4linux-ng -r $DC_IP -R 10000 -oA enum/enum4linux 2>/dev/null

# Combine + dedupe results:

one-time setup — Windows hashcat callable from WSL

What this does: Installs hashcat on the Windows host (which has working GPU drivers) and creates a WSL function that calls it transparently. From WSL you type hashcat and it runs on your GPU.
# 1. On Windows side — download & extract:
#    https://hashcat.net/files/hashcat-7.1.2.7z → C:\hashcat\

# 2. In WSL — verify .bashrc is clean first:

sed -i '/^hashcat()/,/^}/d' ~/.bashrc
bash -n ~/.bashrc && echo "✓ bashrc OK"

# 3. Add the function (NOT an alias — alias breaks with cd):
cat >> ~/.bashrc <<'BASHRC_END'

# Run Windows hashcat from WSL with proper cwd + path conversion
hashcat() {
    local HASHCAT_DIR="/mnt/c/hashcat"
    local args=()
    for arg in "$@"; do
        if [[ -f "$arg" || -d "$arg" ]]; then
            args+=("$(wslpath -w "$arg")")
        else
            args+=("$arg")
        fi
    done
    (cd "$HASHCAT_DIR" && ./hashcat.exe "${args[@]}")
}
BASHRC_END

# 4. Test:
source ~/.bashrc
type hashcat              # should say "hashcat is a function"

# 5. Use it — handles WSL paths automatically:

Why cd matters: Windows hashcat looks for ./OpenCL/ relative to current directory. Without cd /mnt/c/hashcat first, you get ./OpenCL/: No such file or directory. The function above handles this automatically. An alias with cd inline doesn't work — must be a function so path arg expansion happens correctly.
